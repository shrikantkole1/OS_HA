# Asset Sync – Warehouse Device Monitoring

A real-time warehouse device monitoring dashboard deployed with Streamlit.

## Local Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   streamlit run app.py
   ```

## Deploy to Streamlit Community Cloud

1. Push this repository to GitHub.
2. Sign in to [Streamlit Community Cloud](https://share.streamlit.io/).
3. Click **"New app"**, select your GitHub repository and branch, specify `app.py` as the Main file path, and click **Deploy**!
